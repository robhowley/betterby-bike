# NYC cyclist-risk proxy declined on seven corridors but increased on one

NYCDOT's 2014 evaluation reports changes in cyclist injuries normalized by bicycle counts for eight Manhattan
protected-lane corridors. It compares three-year before and after injury periods using representative April–October
12-hour facility counts, not total bicycle trips or distance travelled.[^nyc2014]

| Corridor | Cyclist-risk change | Bicycle-volume change |
| --- | ---: | ---: |
| Ninth Avenue, 16th–23rd | −64.9% | +65% |
| Broadway, 47th–59th | −36.4% | +108% |
| First Avenue, 1st–34th | −53.9% | +160% |
| Second Avenue, 2nd–14th | −43.8% | +49% |
| Second Avenue, 23rd–34th | −54.1% | +60% |
| Eighth Avenue, 23rd–34th | −2.4% | +9% |
| Broadway, 18th–23rd | +11.2% | +28% |
| Columbus Avenue, 77th–96th | −37.6% | +51% |

The risk changes come from p. 9; appendix count changes use averages of before/after 12-hour counts at one named
location per corridor. Broadway (18th–23rd) had a higher cyclist-risk proxy even though its all-user injury crashes
fell 33%. Eighth Avenue's risk change was nearly flat. These are not uniformly large cyclist improvements.[^nyc2014]

Short counts must represent exposure across multi-year injury periods, and the presentation does not give raw
corridor cyclist-injury counts, count dates/sample sizes or confidence intervals sufficient to reproduce or assess
precision of these estimates. Its corridor boundaries also vary between overview and detailed slides; this table uses
the risk table's boundaries. Different prior facilities, signal designs, lane changes and network changes preclude a
controlled comparison of mixing zones versus split-phase signals. No untreated safety control separates project effects
from other trends.[^nyc2014]

Bicycle-volume growth can include route diversion, not just new cycling. These corridor measures are neither absolute
injury rates nor the separate citywide killed/severely-injured indicator.
